KEY IMPROVEMENTS IN RETRAINING
================================================================================

LOSS FUNCTIONS:
  ✅ Dice Loss         → Optimizes F1 directly (not just BCE)
  ✅ Focal Loss        → Focuses gradient on hard examples
  ✅ BCE Loss          → Multi-class binary cross-entropy
  ✅ Combined          → All three weighted together

CLASS WEIGHTING:
  marine_debris:   3.71× weight (rare, needs emphasis)
  sargassum:      19.45× weight (rarest, highest weight)
  turbid_water:    1.45× weight
  organic:        13.03× weight
  cloud:          21.56× weight (rarest)

AUGMENTATION (Applied during training):
  • Horizontal Flip (50% probability)
  • Vertical Flip (50% probability)
  • Rotation ±45° (50% probability)
  • Gaussian Noise (30% probability)
  • Random Brightness/Contrast (30% probability)

LEARNING STRATEGY:
  • Learning Rate: 1e-4 (lower = more stable training)
  • Optimizer: AdamW (with weight decay 1e-5)
  • Schedule: ReduceLROnPlateau (halve LR if no improvement)
  • Early Stopping: Stop if F1 doesn't improve for 15 epochs
  • Gradient Clipping: Max norm 1.0 (prevents explosion)
  • Batch Size: 16 (adjust to 8 if OOM)

TROUBLESHOOTING (Common Issues)
================================================================================

ISSUE: "CUDA out of memory" error during training
FIX:   Cell 2 of Retrain notebook, change:
       BATCH_SIZE = 16  →  BATCH_SIZE = 8

ISSUE: "ModuleNotFoundError: rasterio / albumentations"
FIX:   Cell 1 installs them. Make sure you run Cell 1 first.

ISSUE: "Models not found after training"
FIX:   Cell 13 output shows saved files. If empty:
       - Check Cell 2 paths are correct
       - Run: !ls /content/drive/MyDrive/FYP_models_improved/

ISSUE: "Can't find models during evaluation"
FIX:   Cell 2 of evaluation notebook:
       MODEL_DIR = "/content/drive/MyDrive/FYP_models_improved"
       (Must match exact path where they were saved)

ISSUE: "Training very slow (>60s per epoch)"
FIX:   Usually means GPU not in use. Try:
       1. Run: !nvidia-smi (check GPU listed)
       2. If CPU: Restart runtime (Runtime → Restart Runtime)

ISSUE: "F1 score not improving during training"
FIX:   This is normal for first 5-10 epochs. Wait for convergence.
       Check console: "Loss" should be decreasing.

ISSUE: "Colab session disconnected / timeout"
FIX:   Free Colab: ~12 hour limit before disconnect
       Solution: Use Colab Pro ($10/mo) for unlimited sessions
       OR: Your checkpoints are saved to Drive, can resume later
