IMPROVEMENTS IN RETRAINING NOTEBOOK
================================================================================

✅ LOSS FUNCTIONS
   - Dice Loss: Optimizes F1 directly
   - Focal Loss: Focuses on hard examples
   - BCE: Class-weighted binary cross-entropy
   - Combined: All three weighted (BCE + 0.5*Dice + 0.3*Focal)

✅ CLASS WEIGHTING
   - marine_debris:   3.71× weight (rare class)
   - sargassum:       19.45× weight (rarest)
   - turbid_water:    1.45× weight
   - organic:         13.03× weight
   - cloud:           21.56× weight (rarest)

✅ AUGMENTATION
   - HorizontalFlip (50%), VerticalFlip (50%), Rotate ±45° (50%)
   - GaussianNoise (30%), RandomBrightnessContrast (30%)
   - Applied during training only (not validation/test)

✅ LEARNING STRATEGY
   - Learning rate: 1e-4 (lower = more stable)
   - Optimizer: AdamW with weight decay (1e-5)
   - Scheduler: ReduceLROnPlateau (halve LR if no improvement)
   - Early stopping: 15 epochs without F1 gain
   - Gradient clipping: max norm 1.0

✅ AUTOMATIC SAVING
   - Best checkpoint: Saved every epoch to Drive
   - Final weights: Saved after training completes
   - Never lose progress if Colab disconnects

TROUBLESHOOTING
================================================================================

PROBLEM: "ModuleNotFoundError: albumentations"
FIX: Cell 1 installs it. Make sure you run that cell first.

PROBLEM: "CUDA out of memory"
FIX: Cell 2 of retrain notebook:
  - Change BATCH_SIZE = 16 to BATCH_SIZE = 8
  - Or reduce image size (if possible)

PROBLEM: "Session timeout / disconnected"
FIX:
  - Free Colab: Normal, happens after ~12 hours
  - Use Colab Pro ($10/mo) for longer sessions
  - Or retrain in multiple sessions (checkpoints save to Drive)

PROBLEM: "Models training very slowly"
FIX:
  - Check GPU is in use: run !nvidia-smi in a cell
  - If CPU, try Restart Runtime and allow GPU reset
  - Check for data loading bottleneck (workers=2, pin_memory=True)

PROBLEM: "F1 score not increasing"
FIX:
  - Check loss is decreasing (console output)
  - If loss flat: learning rate might be too low/high
  - Wait more epochs (models take 5-10 epochs to warm up)

PROBLEM: "Can't find models after retraining"
FIX:
  - Check Google Drive: MyDrive/FYP_models_improved/ should exist
  - Verify notebook cell 13 output (lists all saved files)
  - Update evaluation notebook Cell 2 path
